# פנקס ההוצאות — הוראות התקנה

אפליקציית PWA לניהול הוצאות חודשיות עם תקציבים לפי קטגוריה, גרפים, וסנכרון בענן (Firebase) בין כל המכשירים שלכם. עובדת מצוין באייפון כאפליקציה עצמאית מהמסך הבית, כולל שימוש אופליין.

יש 3 שלבים: **(1)** הקמת Firebase (5 דקות, חד פעמי) → **(2)** העלאת הקבצים לאחסון עם HTTPS (5 דקות) → **(3)** התקנה על האייפון (דקה).

---

## שלב 1: הקמת פרויקט Firebase (חינמי)

1. גשו ל-https://console.firebase.google.com והתחברו עם חשבון Google.
2. לחצו **Add project** (הוספת פרויקט), תנו לו שם (למשל `my-expenses`), אפשר לבטל את Google Analytics (לא נדרש).
3. בתפריט הצד, היכנסו ל-**Build → Authentication** → לחצו **Get started** → בלשונית **Sign-in method** הפעילו את **Email/Password**.
4. בתפריט הצד, היכנסו ל-**Build → Firestore Database** → **Create database** → בחרו מיקום (למשל `eur3` אירופה) → התחילו במצב **production**.
5. לאחר יצירת מסד הנתונים, עברו ללשונית **Rules** והדביקו את התוכן של הקובץ `firestore.rules` שצורף כאן (הוא מוודא שכל משתמש רואה רק את הנתונים שלו). לחצו **Publish**.
6. חזרו למסך הראשי של הפרויקט (סמל בית), לחצו על סמל ה-**</>** (Web app) כדי להוסיף אפליקציית ווב. תנו שם, ואל תסמנו Firebase Hosting.
7. Firebase יציג לכם אובייקט קונפיגורציה שנראה כך:
   ```js
   const firebaseConfig = {
     apiKey: "AIza...",
     authDomain: "my-expenses.firebaseapp.com",
     projectId: "my-expenses",
     storageBucket: "my-expenses.appspot.com",
     messagingSenderId: "...",
     appId: "..."
   };
   ```
8. פתחו את הקובץ **`firebase-config.js`** שצורף כאן, ותחליפו את הערכים בערכים האמיתיים שקיבלתם.

> אין צורך "לשמור בסוד" את המפתחות האלה — הם מזהים ציבוריים של הפרויקט. ההגנה על הנתונים שלכם מגיעה מה-Rules שהגדרתם בשלב 5, לא מהסתרת המפתחות.

## שלב 2: העלאה לאחסון עם HTTPS

ל-PWA להיות ניתן להתקנה על אייפון, הוא חייב לרוץ מכתובת HTTPS אמיתית (לא רק קובץ מקומי). הדרך הכי פשוטה וחינמית:

### אופציה א׳: GitHub Pages
1. צרו חשבון ב-https://github.com (אם אין לכם).
2. צרו repository חדש (New repository), למשל בשם `expense-ledger`.
3. העלו את **כל הקבצים** מהתיקייה הזו (index.html, app.js, firebase-config.js, manifest.json, sw.js, icon-192.png, icon-512.png, apple-touch-icon.png) — גררו אותם לעמוד ה-repo דרך "Add file → Upload files".
4. היכנסו ל-**Settings → Pages**, תחת "Build and deployment" בחרו Source: **Deploy from a branch**, Branch: **main** / **(root)**, לחצו Save.
5. אחרי דקה-שתיים תקבלו כתובת כמו `https://your-username.github.io/expense-ledger/` — זו הכתובת של האפליקציה שלכם.

### אופציה ב׳: Netlify (גרירה ושחרור, אפילו יותר מהיר)
1. גשו ל-https://app.netlify.com/drop
2. גררו את כל תיקיית הקבצים לתוך הדפדפן.
3. תקבלו מיד כתובת HTTPS פעילה. אפשר לשנות שם דרך Site settings.

---

## שלב 3: התקנה על האייפון

1. פתחו את הכתובת שקיבלתם בשלב 2 ב-**Safari** באייפון (חייב Safari, לא Chrome).
2. הירשמו עם אימייל וסיסמה (זה יוצר את החשבון שלכם ב-Firebase Authentication).
3. לחצו על כפתור השיתוף (הריבוע עם החץ למעלה) בתחתית Safari.
4. גללו ובחרו **"הוסף למסך הבית" (Add to Home Screen)**.
5. האפליקציה תופיע כאייקון עצמאי, נטענת במסך מלא בלי סרגלי דפדפן, ותעבוד גם ללא אינטרנט (עם סנכרון אוטומטי כשיש חיבור).

כדי להשתמש באותו חשבון ממכשיר נוסף (למשל אייפד או מחשב), פשוט היכנסו לאותה כתובת והתחברו עם אותו אימייל וסיסמה — כל הנתונים יופיעו אוטומטית.

## שימוש באפליקציה

- **ניווט קבוע**: האפליקציה מחולקת למסכי "ראשי", "קטגוריות", "תובנות" ו"הוצאות" בסרגל תחתון, בלי גלילת עמוד כללית. רשימות ארוכות גוללות רק בתוך המסך שלהן.
- **הוספת הוצאה**: כפתור ה-`+` במרכז סרגל הניווט פותח את חלון הוספת ההוצאה.
- **קטגוריות ותקציב**: במסך הקטגוריות, לחיצה על קטגוריה קיימת פותחת עריכה (כולל מחיקה); "חדשה" מוסיפה קטגוריה עם תקציב חודשי משלה.
- **ניווט חודשי**: החיצים למעלה עוברים בין חודשים; "חזרה להיום" מופיע כשלא נמצאים בחודש הנוכחי.
- **תובנות**: מסך נפרד לשלושת המצבים — פילוח הוצאות, תקציב מול בפועל, ומזומן מול אשראי.
- **מחיקת הוצאה**: במסך ההוצאות, ה-X הקטן בצד כל שורת הוצאה מוחק אותה.

## הערות טכניות

- כל הנתונים נשמרים ב-Firestore תחת `users/{המזהה שלך}/...` ומסתנכרנים בזמן אמת בין מכשירים.
- יש תמיכה בסיסית בעבודה אופליין הן ברמת Firestore (שינויים שנעשים בלי אינטרנט יסתנכרנו כשיחזור החיבור) והן ברמת ה-shell של האפליקציה (service worker) כך שהיא נטענת גם בלי רשת.
- Firebase בשכבה החינמית (Spark) תומך בכמות שימוש גבוהה בהרבה ממה שאפליקציה אישית תצרוך — לא צפויה עלות.
